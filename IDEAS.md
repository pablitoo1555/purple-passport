# Wildcats Trip Finder: Feature Ideas

A running list of features to consider. Effort is a rough guess: **S** = an hour or two, **M** = an afternoon, **L** = a day or more.

## Up next

### Group board with share links (Option 1, decided)
No server needed; works on GitHub Pages.
- [ ] **Share my results** button: puts answers, slider tweaks, stars and name into the page link (M)
- [ ] Opening a shared link shows that person's board (read-only, with "Take the quiz yourself")
- [ ] **Group board** screen: paste everyone's links (or open a combined link) to see:
  - [ ] Group priorities (average of everyone's weights)
  - [ ] Group grade for each place, plus "great for 4 of 6, a stretch for Mike"
  - [ ] Group shortlist: who starred what, sorted by votes
  - [ ] Split by home airport: how the trip looks from KC vs. San Antonio
- [ ] One combined "group link" to send back to the chat once everyone's in (S)
- [ ] Group version of the one-page PDF (S)

## Trip planning

- [ ] **Cost per person:** dollar ranges for flights from MCI and SAT, plus lodging per night split by group size. Replaces the 1–5 "Cost & travel" score in Compare (L, needs research)
- [ ] **Group size input** so cost and lodging math match the real headcount (S)
- [ ] **Lodging type:** "good for a house rental" vs. "mostly hotels," with a rough nightly rate (M, research)
- [ ] **Pick-a-weekend poll:** once a place is chosen, everyone marks which Sept–Nov weekends work, shown over that place's fall calendar (M, uses share links)
- [ ] **Booking shortcuts:** prefilled Google Flights searches from MCI and SAT for the chosen dates, plus Airbnb/VRBO searches for the group size (S)
- [ ] **Fairness check:** flag places where one home airport gets a nonstop and the other a long connection (S)
- [ ] **Drive-from-KC filter:** Lincoln, St. Louis, Ozarks and others where a car beats flying (S)

## Comparing and browsing

- [ ] **Show all 30** instead of only the top 10 (S)
- [ ] **Filters:** nonstop from both airports, drivable from KC, no hurricane risk, has a K-State game, best in October (M)
- [ ] **"Why not #1?"** line on each place, e.g. "Loses to Austin mainly on nightlife" (S)
- [ ] **Sort the list by** match, weather, cost or travel time (S)
- [ ] **Compare from anywhere:** add a place to Compare straight from its detail card without starring it first (S)
- [ ] **Month toggle** (Sept / Oct / Nov) that re-scores weather for that month using the new monthly highs and lows (M)

## Quiz

- [x] Skip the whole quiz or a single question
- [ ] Show which answer pushed each priority, e.g. "Weather +2 from 'Guaranteed warm weather'" (S)
- [ ] A "both are fine" middle answer on each question (S)
- [ ] Optional dealbreakers: "no connections," "no hurricane risk," "under X hours from KC" (M)
